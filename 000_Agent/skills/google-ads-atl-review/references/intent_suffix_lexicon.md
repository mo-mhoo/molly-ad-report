# 意圖字尾判斷方法論

完整教訓見 memory `feedback_google_ads_atl_keyword_optimization`（愛旺斯框架），這裡只放覆盤時
要直接套用的清單跟判斷順序。**核心原則：關鍵字要不要保留看的是文字本身有沒有明確商業意圖，
不分廣泛/詞組/完全比對，既有的精準比對關鍵字也要重新用同一套原則檢查一次。**

## 1. 先判斷產品類別，決定要不要信「無字尾＝可砍」

- **症狀驅動型**（拉肚子/掉毛/腸胃問題才查的品項）：無意圖字尾的搜尋詞（例如「貓咪拉肚子但精神很好」）
  幾乎等於查症狀不是查產品，可以直接歸類為低意圖。
- **保健／常態回購型**（魚油、主食飼料等）：「貓咪吃魚油不掉毛」「貓貓飼料」這類**直接問/搜產品本身**的字，
  即使沒有意圖字尾也可能是考慮階段或回購意圖，實測案例中這類字貢獻了活動 40-60% 的營收。
- 不確定屬於哪一類、或活動橫跨多個子品項時，兩種都當作可能情境處理，一律套用第 2 步的營收交叉核對，
  不要只憑字尾判斷就下結論。

## 2. 意圖字尾清單（含同義詞——字串比對抓不到語意，一定要列變體）

| 分類 | 詞彙變體 |
|---|---|
| 評測比較 | 推薦、評價、比較、評比、排行榜、推介、心得、心得分享、開箱、實測、優缺點 |
| 社群討論 | ptt、dcard、心得文、討論、評論 |
| 品牌/競品詞 | 各品牌名稱本身（含常見錯字/簡稱） |
| 功效/成分 | 功效、有效嗎、有用嗎、成分、劑量 |

這份清單不是固定的——每次覆盤新品項前，先想一輪同義詞變體（例如「評比」漏列導致「貓糧評比」被
誤判成無意圖，被 Molly 抓到才補上），必要時執行後再用同義詞回頭複查一次有沒有誤殺。

## 3. 判斷順序（不能只看字尾就一刀切）

1. 用 `queries.search_terms_zero_conversion()` 抓零轉換花費的搜尋詞（所有比對類型）。
2. 對照第 2 節清單標記「有無意圖字尾」。
3. **有字尾的字**：人工複查有沒有離題字混進來（例如「寵物鮮食推薦」字尾是「推薦」但主題是
   鮮食不是查詢中的品項，機械比對會誤判成保留）——標「有字尾但離題」，一樣建議暫停。
4. **無字尾的字**：用 `queries.keyword_revenue_lookup()` 查該關鍵字本身（不是這筆 search term）
   有沒有實際營收貢獻。**只有「無意圖字尾 ∩ 零營收」的交集才建議暫停**；無字尾但有實際營收的字
   一律保留，即使花費看起來不低。
5. 輸出建議清單時，每一條都要附「暫停理由」（無字尾+零營收 / 有字尾但離題 / 純症狀查詢），
   不要只丟關鍵字文字，方便 Molly 一眼判斷合不合理。

## 4. 廣告文案配套（列入建議清單的附註，不在這個 skill 執行）

- 關鍵字意圖類型改變後，文案（尤其 RSA 的 DKI fallback text）要重新檢視是否還匹配。
- RSA 的 headlines/descriptions 不能用 `AdGroupAdOperation.update` 直接改，只能新建修正版；
  新建後**不要順手暫停舊版**，新舊並存輪播到新版有足夠數據才考慮暫停，且暫停動作要先問過 Molly。
- 廣告文案避免直接寫競品品牌名稱，即使關鍵字有鎖競品詞。
