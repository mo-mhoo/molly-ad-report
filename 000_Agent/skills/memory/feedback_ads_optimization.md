累積記錄 AI 給出的廣告優化建議與用戶實際採納/結果的落差，用於 [[project-ads-optimization-training]] 目標。

**Why:** 用戶設定 2026-08 前讓 AI 優化判斷達到人類90分標準，需要持續校正。

**How to apply:** 每次給優化建議後追問結果，新增條目於下方，格式：「情境 → AI建議 → 人類實際判斷/結果 → 原則」。

## 紀錄

### 案例1：轉換BTL｜新客｜魚油（2026-06-11，ROAS 1.82, $3,679, 2購買）

**AI 原本判斷**：直接看單週 ROAS < 2 標示為警示對象。

**人類實際判斷框架（更完整）**：
1. **先依 campaign 命名定義目的與KPI門檻**——名稱含「新客」代表長期測試不同新客受眾，期望 CPA < 800 且 ROAS > 2.5。先用這組門檻判斷「成效不好」，而不是用通用 ROAS<2 一刀切。
2. **看 WoW 趨勢**，不只看單週——例如 5/29-6/4 這組 ROAS 也偏低，代表不是單週波動。
3. **排除短期活動因素**：去查同期官網是否有檔期活動（看帳戶內命名含「活動」的 campaign），並比對**同期整體帳號 BTL 整盤 ROAS**。
   - 若整體 BTL 同期也差 → 可能是檔期結束的全帳號性波動，先觀察。
   - 若整體 BTL 同期是好的，但這組差 → 判定為**結構性問題**（受眾或素材要換）。
4. **結構性問題的處理順序**：優先調整受眾，而非先換素材。等有「新的、已驗證高轉換的素材」之後才導入這個新客開發 campaign——不會貿然把未驗證素材投進新客測試組。

**原則**：分析 BTL「新客」型 campaign 時，套用 CPA<800/ROAS>2.5 作為其專屬KPI門檻（非通用ROAS<2）；診斷流程＝WoW趨勢 → 排除檔期因素(比對同期整體BTL ROAS) → 結構性問題先調受眾、新素材驗證後才導入新客組。

### 案例2：檔期週分析方法（2026-06-25，毛孩時代 618 ASC 比較文）

**AI 原本判斷**：遇到 618 等檔期週，用 WoW 比對，看到 ASC ROAS 下滑後推論「活動 RT 搶轉換」為主因，建議觀察一週。

**人類實際判斷框架（更完整）**：
- **檔期週不應做 WoW 比對**——618 週 vs 前一週根本是不同情境，WoW 無意義
- **正確做法是 YoY**：今年 618 週 vs 去年 618 同期。下滑幅度是「預期範圍內的正常波動」還是「超出預期的異常」，才是決定要不要調整的依據
- YoY 持平或小幅下滑 → 正常，不需動
- YoY 明顯惡化（例如 ROAS 去年 5.0、今年 2.6）→ 才是需要診斷調整的信號

**原則**：遇到電商大檔（618、雙11、雙12等），診斷流程改為：**先做 YoY 比對 → 判斷下滑是預期還是異常 → 再決定是否需要介入**。WoW 在檔期週是噪音，不是信號。

**Why:** 大檔期的市場行為（受眾競標成本、轉換率、AOV）每年都不同，但同一個檔期的結構是可比的。WoW 比的是「活動 vs 平常週」，先天就不公平。

### 案例3：帳號層指標混用 + MTD MoM/YoY 分析框架（2026-07-02，毛孩時代 轉換BTL｜新客｜關節）

**AI 的錯誤**（雲端Routine觀察到）：
1. 單看 WoW 把「關節」campaign 判斷為「結構性改善訊號」，但拉 MTD MoM 後發現是月度大幅下滑中的小反彈，結論完全翻轉
2. 帳號整體 blended ROAS 下滑 26% MoM（2.42→1.78）被誤判為 BTL 問題，實際是 ATL 流量花費暴增 181% 稀釋了整體數字
3. 在 campaign 尚未上線的情況下，寫出「YoY」標籤

**人類指出的正確框架**：
1. **WoW 只能判斷方向，MTD MoM/YoY 才是結構性問題的主軸**——WoW +75% 是噪音層級的回彈，不該被當作轉強訊號
2. **帳號層指標若混合 ATL/BTL，會被規模差異污染**——必須先拆開 ATL/BTL 再算 MoM/YoY，才能做有意義的對照；ATL 用流量指標（CTR/CPC/Frequency），BTL 用轉換指標（ROAS/CPA）
3. **YoY 標籤使用條件**：campaign 去年同期必須有數據才能標 YoY；新 campaign 只能做 MoM，不能捏造 YoY 欄位
4. **個案優化的優先順序**：先確認帳號級花費策略（618前蓄水是否刻意）→ 再看個別 campaign——不要因為單一 campaign 指標差就急著動，可能是帳號整體策略造成的

**原則**：
- 單週 WoW 只看趨勢方向，MTD MoM 才判斷結構性問題，大檔期用 YoY
- 帳號層 blended ROAS 變化，必先拆 ATL/BTL 再解讀，不可混用
- YoY 只用於「去年同期有跑、有數據」的 campaign，否則只寫 MoM
- 個案優化行動前，先確認是否為整體帳號層策略決策（如刻意加碼 ATL 蓄水），排除後才針對個案動手

### 案例4：拿「今天」未過完的數據當異動生效佐證（2026-08-12，毛孩時代 腸胃益生菌 Google Ads 廣泛→詞組比對）

**AI 的錯誤**：批次暫停廣泛比對關鍵字後，用戶截圖顯示「今天」費用/點擊比對照期少很多，AI 拿這個當作「異動已生效」的佐證。

**人類指出的錯誤**：當天還沒過完，時數本來就少，費用/點擊自然比完整一天的對照期低，這跟關鍵字有沒有暫停沒有因果關係，是基本的比較邏輯錯誤——不完整區間 vs 完整區間本來就不能直接比大小。

**原則**：**判斷「異動是否生效」只能靠直接查詢當下實體狀態**（例如重新查 API 確認 criterion 的 status/match_type），不能拿「當天」這種還在進行中、尚未完整的區間流量數字當因果證據；要看流量/成效層面的實際影響，必須等區間走完（完整一天以上）才有比較意義。這跟 [[feedback_data_comparison_range]] 的精神一致——先確認比較區間對不對稱，再下結論。
