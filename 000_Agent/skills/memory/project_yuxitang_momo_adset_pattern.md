御熹堂_CPAS_momo 帳號（`ad_account_id = 7609150239116011`）的 adset 命名邏輯跟官網（見 [[project_yuxitang_activity_adset_pattern]]）不一樣——官網是按「受眾輪廓」(熟女/新客/男性)分，這個 momo 帳號是按**再行銷漏斗階段**（瀏覽 VC／加購 ATC／購買 PUR 的時間窗）分眾。鋪活動素材時要判斷「這支素材的訴求適合哪個消費階段」，不是套用固定名單。

**這帳號是 CPAS 協作帳號**，素材 creative 都帶 `product_set_id`（目錄結構），照 SKILL.md 規則一律用**整支複製**（重用同一顆 creative_id），不要用 post id 方式建（那是給非目錄的官網單圖/影片用的，見 [[feedback_reuse_creative_id_is_not_default]]——CPAS 是那條規則明講的例外）。

**內容-受眾判斷原則（不是死板套用上面清單）**：
- 「滿額贈」類訴求（鼓勵多花錢湊贈品門檻）→ 適合高購買意圖受眾：ATC(10)、PV+ATC(1)-new、VC+ATC(7)、優惠受眾。不適合鋪給完全沒互動過的冷新客（CPAS高潛排除PUR這種）。
- 「TOP3/熱銷組合」種草類訴求（認知/考慮階段）→ 適合鋪廣，新客舊客都可以，包含冷新客受眾。
- 每次鋪新素材前，先看這批 adset 目前有沒有變動（新的/淘汰的），也要看這批的訴求跟哪個漏斗階段對得上，不要只看「哪個adset歷史上最常用」就直接套。

**Adset 容量限制**：這個帳號有些 adset（尤其舊客RT活動下的「舊客｜PUR(180)」）歷史廣告堆很多，容易撞到 Meta 每 adset 50 支上限（含PAUSED），遇到建立失敗要先查是不是這個原因，處理方式見 [[feedback_mcp_no_ad_delete_use_graph_api]]。
