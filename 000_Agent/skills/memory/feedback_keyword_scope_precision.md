幫 Molly 分析「毛孩時代貓飼料廣告 YoY」時，一開始用寬鬆規則（campaign/ad 名稱含「貓」字）去抓 Meta/Google 廣告資料，結果混入了貓砂、貓用保健品(皮膚益生菌等)、貓相關舊客再行銷等大量非飼料品項，把「全部貓相關廣告花費打平（+2%）」的結論呈現給使用者。Molly 多次糾正（先指出個別品項不算飼料/糧，最後直接說「我要看貓飼料+貓糧不是全部貓 你有懂嗎」），重新用精準規則（名稱同時含「貓」與「飼料」，或含「貓糧」）之後，結論完全相反——貓飼料花費其實是**下滑 33.9%**，不是打平。

**Why：** 使用者要問的是特定品項（貓飼料）的表現，用上位詞/大分類（貓）做關鍵字比對雖然「涵蓋率更高、比較不會漏抓」，但會把不相關的品項（貓砂、保健品）也算進來，稀釋甚至反轉真正的訊號。這種分析情境下「精準但可能漏抓」遠比「寬鬆但摻雜雜訊」更接近使用者要的答案；使用者已經明確表達了兩次「這不是我要的範圍」的挫折，第三次才把規則講死。

**How to apply：**
- 之後遇到「分析某個具體品項/SKU類別的廣告或業績表現」的請求，關鍵字比對規則優先設計成**精準對應該品項**（例如同時要求「品類詞」+「品項詞」都出現，如「貓」+「飼料」），而不是只用品類詞（「貓」）广泛比對。
- 若品類詞本身橫跨多個子品項（貓可能對應飼料/砂/保健品/零食等），分析前應該先花一輪時間列出實際 campaign/ad 命名清單，辨認哪些是真正對應目標品項的，再決定比對規則，而不是先用寬規則出報告再等使用者一一挑錯。
- 見 [[project_google_ads_integration]] 的類似教訓（純用 'BTL' 字串比對漏掉 'BT｜' 開頭活動）——關鍵字比對規則的設計本身就是容易出系統性偏差的地方，交付分析結果前最好先抽查比對命中清單，讓使用者確認範圍對不對，而不是等結論被質疑才回頭修。
- 相關：[[project_maohai_official_campaign_structure]]（毛孩時代同一素材要鋪三種平行campaign邏輯，品項/受眾標籤分散在不同層級，命名不直觀）。
