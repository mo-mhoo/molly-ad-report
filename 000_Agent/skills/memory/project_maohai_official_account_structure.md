毛孩時代_官網帳號（`1318362572209550`）裡幾個之後常會用到的固定結構（2026-09-06 觀察）：

**1. 上稿區**：campaign「Ad上稿區」(`120210127210240026`，本身PAUSED) 底下有個固定 staging adset，新素材（單圖/影片）常先建在這裡，狀態PAUSED，之後再複製到真正投遞的adset。跟 [[project_meta_ads_creative_duplication]] 提到的momo/蝦皮CPAS帳號上稿區是同一種操作習慣，但這是官網帳號的獨立campaign（ID不同）。

**2. 流量ATL(Interact)｜新客 campaign**（`120235887157880026`）：這個campaign底下是「新貼文｜XX」這種**依內容主題分眾**的adset結構，不是受眾分眾。目前(2026-09)10組ACTIVE：
- 新貼文｜新品/新內容 (`120248350906570026`)
- 新貼文｜狗 (`120248337756570026`)
- 新貼文｜情緒粉/免疫力 (`120240504998900026`)
- 新貼文｜比較文 (`120237456306810026`)
- 新貼文｜活動 (`120236259363790026`)
- 新貼文｜魚油 (`120236258293810026`)
- 新貼文｜貓 (`120236090870500026`)
- 新貼文｜腸胃 (`120236090465660026`)
- 新貼文｜官網文 (`120239411014300026`)
- 新貼文｜關節 (`120235887157580026`)

複製素材到這個campaign時，依素材內容主題挑**單一**對應adset（不是像新客LAL那樣全灑），沒有專屬主題（例如犬貓通用、跨品類）的素材要跟Molly確認要放哪個最接近的類別，不要自己猜。

**3. 轉換BTL｜活動｜新客(LAL)(X批次預算) campaign**（`120213168328740026`）：全館促銷/新客首購優惠類素材的常用目標，3組ACTIVE adset（類似受眾3%-會員名單`120235658520130026`、寵物展名單`120213168328630026`、毛孩時代_IG追蹤`120213168328520026`），這類素材通常3組adset都放。

**Why**：這天幫Molly把上稿區4支素材（指定飼料買一送一、貓砂買一送一、全館活動_首購折100、全館活動_獸醫x首購）分別複製到新客LAL(11支廣告)跟interact campaign(4支廣告)，過程中查出這些campaign的adset結構，記下來下次不用重查。

**How to apply**：之後在這個帳號遇到「複製廣告到interact」「複製廣告到新客LAL」這類指令，可以直接引用上面的adset清單當候選，但ACTIVE狀態可能會變，執行前還是要重新查一次確認還在投遞。
