**核心判斷原則（愛旺斯框架）**：關鍵字要不要保留，看的是**文字本身有沒有明確商業意圖字尾**（推薦/評價/比較/ptt/dcard/品牌/功效），跟現在是廣泛/詞組/完全比對**無關**。

**Why：** 愛旺斯分享的實測——把廣泛比對全改詞組比對、關鍵字只鎖「品牌+推薦/比較/評價」這類明確意圖字，排除罐頭飼料等不相關字，一週後花費 -50%、營收 +5~10%。套用到毛孩時代「腸胃益生菌」ATL活動驗證同樣模式：廣泛比對佔84%花費，其中搜尋字詞層級零轉換花費佔62%（部落格子帳號同款活動甚至100%零轉換）。

**執行流程：**
1. 先用 `search_term_view` 報表抓零轉換花費最高的搜尋詞，確認廣泛比對真的在燒不相關流量（毛孩案例：零轉換字幾乎都是「貓咪拉肚子但精神很好」這類純症狀查詢，不是「查詢中的購物意圖」）。
2. 用「有無商業意圖字尾」分類保留/暫停，**不分比對類型、一視同仁套用同一套標準**——這點曾漏掉：一開始只重新篩廣泛比對，「既有 EXACT/PHRASE 一律保留」，結果漏了一批純症狀的 EXACT 字（例如「貓 拉肚子」EXACT $500花費只賺$1），被 Molly 抓到才回頭補篩。**教訓：既有的非廣泛比對關鍵字，也要重新用同一套意圖原則檢查一次，不能因為它「已經是精準比對」就假設它沒問題。**
3. 先測試 1 個暫停 + 1 個新增，確認帳號真的生效，再批次執行大量操作——降低大規模操作出錯的風險，也是 Molly 明確要求的做法。
4. 批次執行後**用 API 直接查詢 `ad_group_criterion.status` 驗證**，不要相信 Google Ads「變更記錄」頁面：該頁面有索引延遲，且會把同一批次的多筆操作彙整/分頁顯示，看起來只有一兩筆不代表其他沒生效。
5. **每次執行完關鍵字調整，都要建立一個 Claude 雲端 routine（`/schedule` 或 `RemoteTrigger`），排在 5-7 天後自動覆盤**——這是 Molly 明確要求的固定流程，不用每次問。Prompt 要自包含（雲端 agent 沒有本次對話記憶），內容至少包含：改了哪個活動/campaign.id、改了什麼（暫停/新增哪些類型的字、文案異動）、要它比較異動前後花費/營收(用 conversions_value)/ROAS 並列出實際比較日期、如果沒有 Google Ads MCP connector 就誠實列檢查清單而不是編數字。可參考本次「腸胃益生菌ATL優化-7天覆盤提醒」routine 的做法。

**不同品項的意圖字尾規則不能照搬（2026-08-18 魚油／全貓飼料案例補充）：**
- 腸胃益生菌是症狀驅動型購買（拉肚子/便秘才查），無意圖字尾的字幾乎等於「查症狀不是查產品」，可以放心砍。
- 但魚油、全貓飼料這種保健/常態回購品項，「貓咪吃魚油不掉毛」「貓貓飼料」「貓咪飼料」這類無意圖字尾但**直接問/搜產品本身**的字，其實已經是考慮階段或回購意圖，貿然套用同一套規則砍掉會誤傷（魚油案例：這批字貢獻了活動62%的營收；全貓飼料案例：貢獻了將近一半營收）。**正確做法：先看無意圖字尾清單裡有沒有實際營收，有營收的即使沒有字尾也要保留，只砍「無意圖字尾＋零營收」的交集**，不能只看字尾就一刀切。
- 分類「有意圖字尾」時也要人工複查有沒有離題字混進來——例如「寵物鮮食推薦」雖然有「推薦」字尾，但主題是鮮食不是魚油，機械式關鍵字比對會誤判成保留，要额外挑出來處理。
- **意圖字尾清單本身要涵蓋同義詞，不能只列固定幾個詞**：全貓飼料案例中「貓糧評比」「飼料評比」被誤判成無意圖暫停，原因是意圖字尾清單只列了「評價」「比較」，沒列「評比」——雖然語意上「評比」明顯等於評測比較，但字串比對抓不到，被 Molly 問「為什麼評估暫停」才發現是清單漏詞，不是真的沒意圖。**日後設計意圖字尾清單時要多想同義詞變體（評比／排行榜／推介／心得分享等），或執行後額外用同義詞關鍵字回頭複查一次有沒有誤殺。**

**驗證陷阱（重要教訓）：**
- **不能拿「今天」還沒過完的流量數字（花費/點擊下降）當異動生效的因果佐證**——不完整區間跟完整對照期本來就不能比，這是基本比較邏輯錯誤，被 Molly 當場糾正。跟 [[feedback_data_comparison_range]] 精神一致：先確認比較區間對不對稱，才能下結論。
- **帳戶裡同一組關鍵字可能有「同名分身」散落在好幾個不同活動**（例如毛孩時代帳號還有「部落格-腸胃」系列、獨立的「症狀字」廣告群組），查證某個關鍵字狀態時，要同時確認 `campaign.status`／`ad_group.status`／`ad_group_criterion.status` 三層——如果活動本身整個是 PAUSED，裡面關鍵字顯示 ENABLED 也不會真的花錢，不要誤判成「漏處理」。
- Google Ads UI 是單頁應用，關鍵字列表頁面常常需要**離開再重新進入**才會反映最新狀態，單純按瀏覽器重新整理不夠。
- **判斷活動整體業績別只看該活動自己的最後點擊歸因營收**：ATL 活動本身的 `conversions_value` 可能下滑，但用 GA4 電商項目（item）維度查該商品「不分流量來源」的整體營收，可能是持平或上升的——ATL 砍掉的低意圖流量本來就很少真的走到購買，商品實際業績多半是其他管道貢獻的。判斷 ATL 關鍵字優化有沒有傷到生意，要交叉看商品整體業績，不能只看單一活動的自歸因數字。
- **內容與流量可能已經脫節，執行關鍵字優化前順便查一下 landing page**：全貓飼料案例發現廣告文案跟關鍵字裡點名的「莫比/原點/渴望」品牌，其實已經不在文章最新版的比較名單裡（文章更新成 Orijen歐睿健/毛孩時代/皇家/Hyperr超躍/法米納/倍力），代表帳戶內容曾經改版但廣告端沒同步更新。優化關鍵字時應該一併確認 landing page 現況，抓出這種內容與流量對不上的情況。

**廣告文案配套原則：**
- 關鍵字意圖改變後（症狀型→比較型），文案要重新檢視是否還匹配，尤其**動態關鍵字插入（DKI）的預設字**（fallback text）容易被忽略，是最先過時的地方。
- 新增文案測試新角度時，**建議新建一則完整的新 RSA 廣告讓系統跟舊廣告輪播比較，不要直接覆蓋改寫正在跑、已有數據的既有廣告**。
- 廣告文案避免直接寫競品品牌名稱（商標爭議風險），即使關鍵字有鎖競品品牌詞（例如「汪喵星球益生菌評價」），文案用「多品牌實測比較」這種中性角度承接即可，不用在文案裡點名對手。
- **技術限制：RSA 廣告的 headlines／descriptions 不能用 `AdGroupAdOperation.update` 直接修改**（Google Ads API 會回 `cannot be modified by 'UPDATE' operation`），只能新建一則修正版取代。
- **新建修正版 RSA 取代舊版時，不要順手把舊版暫停**——被 Molly 糾正：新版還沒有數據之前，舊版要保留繼續跑，新舊並存輪播，等新版累積到足夠數據能判斷成效後才考慮暫停舊版。**日後任何廣告啟用/暫停的開關動作，執行前都要先跟 Molly 確認過，不能因為「建了新的取代品」就自動推論「舊的該關掉」。**
