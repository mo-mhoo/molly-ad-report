**這則記憶只是 2026-09-11 當下查到的歷史快照，不是可以直接套用的固定規則。** Molly 明確要求：adset 選擇每次都要重新判斷，不能因為這裡寫過某個 adset ID 就預設沿用——帳號裡的 adset 會不定期換新/淘汰（下面 UC2 那條就是活生生的例子：舊的舊客adset `120239975055450735` 已經被換成 `120253655360380735`），RT adset 也曾在兩個之間交替過。**每次執行前都要重新用 `ads_get_ad_entities` 查一次該campaign底下目前有效的adset,並跟 Molly 確認候選清單，不要直接讀這篇記憶就決定要鋪去哪。**

以下是 2026-09-11 查到的鋪法慣例，可以當作「這帳號通常怎麼操作」的背景知識、幫助你更快理解候選清單的邏輯，但具體 ID 一定要重新驗證：

御熹堂官網帳號（`ad_account_id = 800743741924152`）裡，帶走期字首（`[~MM/DD]`）的「活動」素材，既有慣例是**同一支素材同時複製鋪進好幾個平行的常態活動 adset**，不是只選一個：

**全館活動（跨品項通用促案，素材名稱通常帶 `_All`）**：
- 轉換BTL(CPA)｜新客｜活動（campaign `120240734238290735`）→ 近期用「新客｜LAL高價值會員(10%)排除名單」(`120250122779860735`)；更早的批次用「新客｜RT(180)排除會員名單」(`120244270494020735`)
- 轉換BTL｜舊客｜活動（campaign `120239086845330735`）→ 「舊客｜名單+PUR(180)排除PUR(60)」(`120239975055450735`)
- 轉換BTL｜RT｜活動（campaign `120221937606170735`）→ 「舊客｜VC7+ATC7」(`120221937606310735`)
- 轉換BTL｜ASC｜加強活動（campaign `120249606840910735`）→ 「ASC｜會員日」(`120250334732670735`)，這個不是每批都鋪，需跟 Molly 確認要不要加

**UC2（有自己的專屬 campaign）**：
- 轉換BTL｜ASC｜UC2（campaign `120234404286380735`）→ 「ASC｜活動」(`120247179057390735`)
- 轉換BTL｜舊客｜活動（campaign `120239086845330735`）→ UC2 專屬的「舊客｜UC2｜PUR(720)排除PUR(180)」(`120253655360380735`)，這個 adset 會不定期換新（舊版是共用 `120239975055450735`），鋪之前先確認帳號裡有沒有更新的 UC2 專屬舊客 adset
- 轉換BTL｜RT｜活動（campaign `120221937606170735`）→ 「舊客｜VC7+ATC7」(`120221937606310735`)

**魚油／紅麴（沒有專屬 campaign,鋪法同全館活動的新客/舊客,但historically用另一個新客adset）**：
- 轉換BTL(CPA)｜新客｜活動 → 「新客｜RT(180)排除會員名單」(`120244270494020735`)（跟全館活動最新批次用的新客adset不同,要留意）
- 轉換BTL｜舊客｜活動 → 「舊客｜名單+PUR(180)排除PUR(60)」(`120239975055450735`)
- 轉換BTL｜RT｜活動 → 歷史上在「舊客｜VC7+ATC7」(`120221937606310735`)跟「舊客｜PV(30)+ATC(30)」(`120221937606340735`)之間交替出現過，沒有固定答案。**2026-09-11 這批問過 Molly 後這次用了 VC7+ATC7，但這不代表下次也用這個——Molly 明確說希望每次都重新判斷/重新問她，不要把這次的選擇當成之後的預設值。**

**共用做法（2026-09-11 更正，見 [[feedback_reuse_creative_id_is_not_default]]）**：**不要**預設用 `creative: {"creative_id": "<素材庫裡那支ad的creative_id>"}` 直接重用同一顆 creative——這個做法 2026-09-11 被 Molly 當場糾正過兩次（一次是活動素材批次、一次是這支 UC2 常態影片），正確預設是照 SKILL.md 的判斷規則走：單圖/單影片（非目錄/輪播）用 **post id 建立**（`creative: {"object_story_id": "<素材庫裡那支ad的creative的effective_object_story_id>"}`，格式 `pageID_postID`，讚數留言才會累積在同一則貼文上），只有目錄/輪播結構才整支複製。**重用既有 creative_id 只在遇到 App 開發模式擋創意發布的 subcode 1885183 錯誤時才當備案用**（見 [[project_meta_cpas_app_dev_mode_blocker]]），不是每次的預設做法。`ad_name` 維持素材原名不加後綴（見 [[feedback_meta_ad_copy_ad_naming]]），新建 ad 預設 PAUSED，是否要现在就 activate 要另外問 Molly（見 [[feedback_activity_creative_cloud_routine]] 的走期起始日自動開啟邏輯——如果起始日 00:00 已過，要當面問她要不要現在開）。

素材庫本身（campaign「Ad 素材庫」`120210717941760735`）是暫存區,不是投放位置,見 [[feedback_meta_ad_copy_staging_adset_not_final]]。
