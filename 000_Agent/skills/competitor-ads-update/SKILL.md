## 執行步驟

### 1. 載入工具

用 `ToolSearch` 載入 `mcp__0d74ec43-1f83-4839-b189-d6ae29575565__ads_library_search`（Meta Ads Library 搜尋工具，這是已連接的 Meta Ads MCP 提供的，不需要另外授權）。

### 2. 找上一版報告當基準

到本機資料夾找檔名最新的 `毛孩時代_alpha_競品廣告分析_更新版*.html`，讀取它——這是這次更新的比對基準跟編輯模板，**不要每次從零重寫**，而是在同一份結構上更新內容、並在開頭寫一段「這次跟上次比有什麼變化」。

### 3. 查品牌廣告

對每個已知 page_id，呼叫 `ads_library_search`，帶 `page_ids=[該id]`、`ad_active_status="ALL"`、`countries=["TW"]`、`limit=50`。這個 API 單次最多回傳 50 則、沒有分頁——這是已知限制，不用嘗試繞過，報告裡照實註明取樣範圍就好。

**如果 Molly 要看廣告的完整文案或示意圖（API 拿不到，只有連結標題）**：改用 `mcp__claude-in-chrome__navigate` 開啟 Molly 自己登入 Facebook 的真實瀏覽器，直接前往 `https://www.facebook.com/ads/library/?id=<廣告ID>`（單則）或 `https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=TW&search_type=page&view_all_page_id=<page_id>`（整個品牌），再用 `get_page_text` 讀出完整文案全文（含品牌故事、成分細節、KOL 業配內容），比 API 豐富很多。內建的 Claude_Browser（無登入）試過會被拒絕或只回傳不相關結果，一定要用 Claude in Chrome。用完記得 `tabs_close_mcp` 關掉開的分頁。

嬌寵醫生已有 page_id（571533563053275），直接用 `page_ids=["571533563053275"]` 查即可，不需要再用 search_terms 猜。如果哪天這個 page_id 查不到資料了，才需要重新用 search_terms 找——**純中文「嬌寵醫生」「嬌寵」或純英文「ProudPet」「ProudPet.TW」都查無結果**（API 找不到匹配時會 fallback 回傳不相關的熱門廣告，例如短劇類），要用**中英混合**「Proudpet 嬌寵醫生」才查得到，這是這個品牌 search_terms 比對的已知怪癖。

### 4. 查 KOL／素人動態

用品類關鍵字（可視情況調整，不用每次都一樣）搜尋 TW 目前投放中的廣告，`ad_active_status="ACTIVE"`，例如「寵物魚油」「貓咪肉泥」「寵物益生菌」「寵物關節保健」。從結果中留意：

- 已知候選帳號（上表）有沒有新素材
- 有沒有新出現、反覆出現、風格像個人飼主/部落客帳號（不是明顯的品牌官方帳號）的新面孔

判斷「像不像 KOL」主要看帳號命名風格（人名/寵物暱稱/日記體 vs. 品牌名+英文對照）跟內容類型（排行/比較/實測文 vs. 純商品促銷）。

### 5. 粗判分類（沿用既有方法論，不要精緻化到需要逐則人工核對）

API 只回傳廣告連結標題文字，沒有完整文案、沒有圖片、沒有結束投放時間，所以分類是用標題文字關鍵字粗判：

- **三層級漏斗**：促購/優惠/免運/限時字樣 → 轉換；比較/評測/知識/症狀警示/獸醫背書字樣 → 導流；純情感/互動字樣（無明顯商品或價格訊息）→ 互動
- **內容主軸**：促購優惠、專業權威（獸醫背書、文獻數量、飼主人數佐證）、商品訴求（成分/機能描述）、問題教育（症狀警示、知識解說）、社會證明（口碑、評價數）
- **品類**：依商品關鍵字判斷（貓砂、腸胃/益生菌、魚油/心血管、皮膚/毛髮、關節/骨骼、眼睛/視力、補水/濕食罐頭 等）

報告裡務必保留「這是關鍵字粗判、不是逐則人工核對」的警示區塊——這是為了讓 Molly 知道這份報告能拿來看方向、不能直接當精確數據引用。
