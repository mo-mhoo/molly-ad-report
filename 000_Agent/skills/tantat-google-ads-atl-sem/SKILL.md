# 愛旺斯貓飼料廣告優化 SOP

> **這是 TSA 同事分享的其他公司（騰達寵物用品有限公司 Tan Tat Pet Supplies）帳戶優化參考 SOP，不是 Molly 自己操作管理的帳戶。**帳戶結構、活動 ID、著陸頁都是騰達寵物專屬，方法論（B 方案、矩陣展開、排除字紀律等）可以參考套用在自己的品牌帳號上，但帳號細節不能跟 TSA 自己的品牌（毛孩時代/御熹堂等）搞混。

騰達寵物「導流廣告 → 比較文著陸頁 → 點 CTA 去官網/蝦皮/momo」模式的優化手冊。
以愛旺斯貓飼料活動為主體，方法同樣適用於狗飼料、優固膚、犬膚沛錠等同模式活動。

## 開始前一定要讀

1. `references/account.md` — 帳戶、活動、著陸頁、轉換動作的事實表（動手前先核對，不要憑記憶）
2. `references/playbook.md` — 方法論：B 方案、矩陣展開、排除字紀律、判斷準則
3. `references/backend-ops.md` — Google Ads 後台的操作限制（**不讀會浪費大量時間**）
4. `references/baseline-2026-08-13.md` — 上次優化後的基準數據，本次檢視要跟它比

## 鐵則（違反就是做錯）

1. **清單先給人看過，說「開始」才動後台。** 關鍵字、排除字一律先列出來確認。
2. **廣告設定好停在暫停/草稿**，等人手動上線。
3. **確定性的計算走報表數字，不要心算或估算。**
4. **失敗要說出來。** 「已完成」不能在沒驗證的情況下講；漏跑、權限不足、只做了一半，明確標記。
5. **只改被要求改的部分。** 不要順手整理其他欄位、不要重排、不要改既有命名慣例。
6. **不確定的數字不進廣告文案。**

## 主流程

### 步驟 1：拉成效（唯讀，可直接做）

在關鍵字頁把日期設「過去 30 天」，篩選「關鍵字狀態：已啟用」，看這些欄位：
曝光／點擊／費用／**轉換次數**／轉換率／平均單次點擊出價／單次轉換費用。

要算出來的三個數字：

- **每日花費** ＝ 近 3–7 天費用 ÷ 天數。判準：**$1,200–2,000 正常；< $1,000 要擴量**（日預算 $2,000）
- **品牌字 vs 意圖字**的費用與轉換佔比（分組方式見 playbook）
- **零轉換但有花錢**的字，列出來但**不要急著砍**（判準見下）

⚠️ 這裡的「轉換」＝點了購買外連（CTA），**不等於實際下單**。回報時一定要講清楚這個限制。

### 步驟 2：搜尋字詞報表（唯讀，可直接做）

同期間、依費用排序，至少看**前 100 筆**（第 100 筆通常已降到約一次點擊的費用，代表後面是長尾）。分成四類：

| 類別 | 處理 |
|---|---|
| 文章沒有的競品品牌 | **排除**（詞組比對）——點進來找不到自己在查的牌子，必然跳出 |
| 品類錯頻（濕糧／處方／腎臟／減重／罐頭／異物種） | **排除**（詞組比對） |
| 自家其他品牌 | **排除**（帳戶層級，見步驟 4） |
| 有量但沒有專屬關鍵字接住的寫法 | **這是補字的依據**，記下來 |

型號字（例如皇家 c30/k36）**不要逐個排除**——有幾十個，是打地鼠；而且它們由「近似變體」帶入，改完全比對會連正常品牌評價流量一起砍掉。

### 步驟 3：補關鍵字（要先給人看清單）

**一律用矩陣展開，不要憑印象逐條列。** 方法與檢查清單見 `references/playbook.md`「矩陣展開」。

貼入前必須自我核對：行數正確／全部帶引號（＝詞組比對）／零簡體字／零重複／與清單逐字比對 0 漏 0 多。
存檔後重載頁面數列數驗證，並確認比對類型沒有被系統改掉。

### 步驟 4：排除字

- **自家其他品牌 → 放帳戶層級**（管理 → 帳戶設定 → 排除關鍵字），才涵蓋全部活動含未來新開的
- **競品與品類錯頻 → 放活動層級**
- **一律用詞組比對，不要用完全比對**（原因見 playbook）

### 步驟 5：回報與記錄

回報格式：**做了什麼／驗證了什麼／還剩什麼**。每個數字都要有前後對照（例：22 → 85）。
把本次的基準數據更新進 `references/baseline-2026-08-13.md` 的格式，供下次比較。

## 後台操作分工（重要，不要硬幹）

Google Ads 後台有些元件對自動化點擊完全沒反應。**Claude 負責貼上前的逐字核對與貼上後的驗證，人負責按最後那顆「儲存」。**
細節與已知可行手法見 `references/backend-ops.md`。硬要自動點「儲存」會發生「把使用者已貼好的內容清空」這種倒退，已經發生過。
