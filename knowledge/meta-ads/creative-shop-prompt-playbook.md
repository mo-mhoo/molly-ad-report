# Creative Shop 提示教戰手冊：用 AI 提示詞產出廣告創意策略

**來源文件**：`(TW Master) Glow up Your Reels with AI - Q2'2026 Creative Event_zh_TW.pdf`（Meta Creative Shop 團隊示範，用「CS Mutual」虛構品牌案例演示）

## 用途

這是把 [reels-ai-creative-2026.md](reels-ai-creative-2026.md) 裡「誘因導向廣告創意框架」流程化、可直接丟給 AI（ChatGPT/Claude 等）執行的 8 步驟提示詞鏈。每一步的輸出是下一步的輸入，最終產出：目標受眾分析 → 誘因清單 → 誘因主題分類 → 受眾族群輪廓 → 鉤引點 → CTA。可套用在幫任何品牌（御熹堂、毛孩時代等）做新素材角度發想時使用。

## 8 步驟提示詞（可直接套模板使用）

### 提示 1：背景說明（建立品牌語境，後續所有提示都會延續這個設定）

```
開始之前，我先分享一些關於我們品牌的重要資訊，以便您在今後的合作過程中參考：
品牌名稱：[插入品牌名稱]
類別/產業：[例如護膚、健身服飾、直接面向消費者的廚具]
核心提供內容：[插入您銷售的商品/提供的服務]
目標受眾：[新增人口統計資料、心理特性、思維]
使命與價值：[選用：最多數行]
關鍵競爭優勢：[新增核心賣點]
品牌語氣和口吻：[例如專業、平易近人、風趣、關愛]
運用這些資訊來決定後續所有內容的表達語氣、訊息呈現方式以及產品亮點。
```

### 提示 2：找出合適的目標受眾

```
太好了，那麼現在能否為我詳細分析一下 [品牌名稱] 在 [國家/地區] 的主要目標受眾群體？
該品牌主要銷售 [產品/服務]，這份分析報告需要用於涵蓋全通路行銷策略中的
全漏斗/漏斗上層/漏斗中層/漏斗下層。
請確保對目標受眾進行深入剖析，並提供大量的實際統計數據與實證重點，
避免使用模糊的量化詞彙，僅使用具體的百分比和統計數據即可。
```

**輸出格式要求**：針對每個受眾群體列出——受眾個人資料（對象描述、規模與成長、人口統計資料、收入與需求）、實證重點（附百分比+資料來源）、漏斗行銷策略（漏斗上/中/下層分別建議）。

### 提示 3：發掘誘因

```
對於 [所選目標受眾] 而言，促使他們採取 [您希望受眾採取的動作，例如選擇線上訂餐
而非親自去餐廳] 的 30 個最常見且最能引起共鳴的動機是什麼？
請確保您的洞察有現實資料的支持。
誘因是廣告受眾洞察報告，可識別目標受眾選擇訂購/購買特定品牌商品/服務的動機，
這 30 個誘因是人們的實際需求與品牌可提供價值之間的紐帶，
請根據上述說明，寫出目標受眾最常見的 30 個相關誘因。
請僅使用實際百分比和統計數據，避免使用含糊不清的字詞和數量，
針對每項統計數據/分析資料附上原始資料/研究連結。
每項誘因皆須以動詞開頭，例如節省時間、避免塞車、想參考不同選擇等等。
```

**追問方向（創意檢查點）**：哪個誘因讓你立即想到多個呈現方式或故事？這些誘因中有哪些可連繫至特定季節或人生階段？

### 提示 4：分類主題

```
將以上 30 項誘因分類成 5 大主題，每個主題包含 6 項誘因。
```

**追問方向**：是否有已經出現但尚未有人討論的主題？哪一個主題值得進一步探討？

### 提示 5：轉換為誘因圖表（方便貼到簡報）

```
請將誘因清單轉換為可輕鬆貼上至 Google 簡報的表格格式。
應採用如下格式：
頂端列是 5 大主題
在每個主題下方使用一個直欄，列出與該特定主題相關的 6 個誘因，個別放置在各自的儲存格中
僅列出主題和誘因，不需要額外儲存格
```

### 提示 6：發掘目標族群（Persona）

```
請根據我的誘因圖表，協助我發掘明確的新趨勢，從而建議不同類型的顧客
（例如新手媽媽、護膚品愛好者，成分懷疑論者），簡要描述這些客群
並包含以下元素：
- 姓名/暱稱（例如：「成分研究者」、「過度焦慮的完美主義者」）
- 他們的身份特徵（人生階段、思維及行為模式）
- 他們重視的事物
- 他們的情緒或實際驅動因素
- 能夠吸引他們的語氣口吻/廣告創意方向
```

**追問方向**：這些目標族群有哪些感覺過於相似？請試著深入分析他們思維、動機或生活方式真正的獨特之處。可以描繪這些目標族群可能會說些什麼、有哪些行為嗎？

### 提示 7：設計引起共鳴的鉤引點

```
針對每個目標族群，撰寫 3-5 個 10 字以內的影片鉤引點。
鉤引點應該具備下列條件：
- 反映其心境或未滿足的需求
- 精準定位、觸動情感，並適用於付費廣告宣傳（而非泛泛而論的通用鉤引點）
- 符合品牌的風格
- 在 Reels 廣告的前 3 秒使人們停指觀看並吸引注意力
- 想像自己是一位創意文案寫手，並為我提供最佳作品
```

**通用 vs. 反映心境的鉤引點對比範例**（官方示範）：
- 通用（避免）：「這是為創作者、經營者和創業者準備的內容秘訣」
- 反映心境（採用）：「這是專為那些每天都堅持發佈內容，卻仍然感覺受到忽視的創作者們準備的支援，您的困擾我都懂。」

**追問方向**：想像自己正在捲動瀏覽內容，這些鉤引點能有效讓你停下觀看嗎？這些鉤引點是否反映真實心境，還是在廣發訊息？不要畏懼重新撰寫提示並繼續探索。

### 提示 8：激發行動和情感的行動呼籲（CTA）

```
為每個鉤引點撰寫清晰且能引發情感共鳴的行動呼籲，目的是促使用戶點擊，
因為這些行動呼籲令人感到符合自身處境，而不是僅僅是公式化造句。
請在一些行動呼籲中嘗試融入我的品牌，但不需要在所有的行動呼籲都加入品牌。
每個行動呼籲都應具備下列要素：
- 反映目標族群的思維或情感
- 令人感到備受關懷、具體且富有人性，而非機械化的通用訊息
- 圍繞目標設計：讓用戶感覺值得立即採取行動
```

**CTA 改寫範例（官方示範，避免公式化）**：
- 不要用「立即購買」 → 改用「以您自己的方式閃耀」
- 不要用「深入瞭解」 → 改用「看看您的皮膚缺乏什麼」
- 不要用「今天下單」 → 改用「讓日常習慣為您帶來效益」

**追問方向**：當你移除品牌名稱時，這些行動呼籲仍可引起共鳴嗎？不要將這些內容當成單純的行動呼籲，而要視為激發用戶購買意願的情感推動力。

## 使用建議

- 這套流程最適合在**新品上市、新受眾拓展、素材角度枯竭（高相似度警訊）**時使用，用來系統性地產出多元誘因角度，而不是憑感覺想標題
- 每一步的「創意檢查點」追問都值得認真做——官方示範顯示，直接把 AI 第一輪輸出當最終稿容易流於公式化（如提示 7、8 的「避免範例」），追問一輪能讓輸出更貼近真實受眾心境
- 產出的鉤引點/CTA 可以直接對應到 `feedback_meta_creative_tag_naming` 的素材切角命名規範，用「訴求角度」欄位歸類
