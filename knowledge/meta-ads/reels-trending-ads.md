# Reels 夯片廣告（Trending Ads）

**來源文件**：`(TW Master) Glow up Your Reels with AI - Q2'2026 Creative Event_zh_TW.pdf`
**狀態**：需要帳號加入允許清單（allowlist）才能使用。僅支援「預訂」購買類型與品牌認知目標，非自助式常規投放產品。

## 是什麼

瞄準與品牌最具文化關聯性的熱門 Reels 內容，安排廣告緊接在該熱門內容之後播出，讓品牌成為「文化焦點」。

## 品牌適用性

Meta 表示遵循最嚴格的品牌適用性標準：
- 觀看次數達 610 萬（案例數據）
- 熱門內容以外，另有「限制」廣告顯示位置的內容規範
- 支援的內容類別：動物和寵物、美容和時尚、汽車和交通運輸、食品和飲品、體育、音樂、商業/金融/投資（新增）、旅遊、電視節目和電影

## 成效數據（Meta 提供，僅供參考）

- 深具意義的品牌影響力占總體未提示品牌知名度比例 **+20%**（相較 YouTube Select +20%、TikTok Pulse +14%，Kantar Context Lab 研究，樣本數 623）
- 廣告回想提升 **+6.6 點**
- 每次曝光廣告回想提升 **+1.5 倍**（相較常規觸及人數行銷活動；根據 59 項指標提升研究跨產業統計整合分析，2025/10–2026/2）

## 建立行銷活動流程

帳號加入許可清單後，可在**行銷活動層級**用切換開關選擇加入：
- 獨立的行銷活動建立流程：該行銷活動中所有廣告組合僅限刊登 Reels 夯片廣告
- 簡化且熟悉的預訂購買流程
- 開啟後即啟用內容目標設定

**主題系列選擇**（2 選項）：
- 所有超夯 Reels：出現在所有最熱門內容旁邊
- 主題：特定類別熱門內容（美妝、體育、時尚等），未來會持續新增更多主題類別

## 規格與檢查清單

| 項目 | 規格 |
|---|---|
| 購買類型 | 僅限「預訂」 |
| 目標 | 僅支援品牌認知 |
| 格式 | 僅限 Reels，建議至少 4 支符合 Reels 最佳作法的影片 |
| 計價方式 | 曝光次數 |
| 排程 | 最早可於投遞前 180 天預訂；最短刊登期間 3 天 |
| 投遞誤差 | 所有廣告預訂投遞目標誤差不超過總花費（曝光次數）的 ±5% |
| 預算 | 由 Meta 業務代表告知的總經費 |
| 歸因設定 | 不適用 |
| 轉換位置 | 不適用 |

**注意**：每個 Reels 夯片廣告行銷活動可包含多個廣告組合，但「所有超夯 Reels」與「主題」必須分別放在不同廣告組合中設定，不能混在同一組。

**延伸**：建議搭配 Meta「關鍵行銷時刻行事曆」規劃投放時機，提升品牌關聯性、發掘更多即時融入文化趨勢的方式。
