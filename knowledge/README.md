# 廣告知識庫

長期累積的廣告平台知識庫，來源多為 Meta/Google 官方訓練簡報、產品說明會文件。目的是把散落的 PDF 簡報整理成可搜尋、可引用的結構化筆記，供之後做廣告優化判斷、上稿決策時查閱。

## 使用方式

- 依平台分資料夾（目前：`meta-ads/`，未來可能新增 `google-ads/`）
- 每份筆記開頭會標註「來源文件」與「日期/狀態」（例如 Beta 功能、活動時間點），因為廣告平台功能更新快，測試版功能未來可能有變動或正式上線，使用前留意時效性
- 這份知識庫存在專案 git repo 裡，可以 commit + push 到 GitHub，其他電腦 `git pull` 後就能取得
